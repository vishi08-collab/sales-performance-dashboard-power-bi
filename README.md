# Sales Performance Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze sales performance, profitability, company-wise quantity, brand contribution, geographical sales distribution, and order fulfillment for 2020–2022.

## Dashboard Preview
![Sales Dashboard](2020%E2%80%9322%20Sales%20Dashboard%20Overview.png)

## Key Performance Indicators (KPIs)

| Metric | Value |
|---|---:|
| Total Sales | 99M |
| Total Cost | 76M |
| Total Profit | 23M |
| Total Orders | 5K |
| Quantity Sold | 13K |
| Profit Margin | 23% |

## Dashboard Features
- Interactive filters for Year, State, City, and Channel
- Monthly sales trend analysis
- Company-wise quantity comparison
- Top 10 cities by total sales
- Brand-wise sales contribution
- Order status analysis
- KPI cards and key business insights

## Key Business Insights
- Zydus leads the company-wise quantity comparison.
- Monthly sales analysis highlights fluctuations in performance.
- Brand analysis identifies the leading contributors to sales.
- Order status analysis compares delivered, dispatched, and cancelled orders.
- Geographical visualization supports city-level sales analysis.
- The dashboard reports a 23% profit margin.
